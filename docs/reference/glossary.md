# 术语表

按主题分组。括号内为英文原词或项目中的标识符。

## 基础

| 术语 | 含义 |
|---|---|
| **Harness** | 驱动模型完成任务的运行时：循环、工具、上下文、状态、生命周期、策略、执行环境与度量的总和。`Agent = Model + Harness` |
| **Run** | 一次任务执行：从一条用户输入开始，到明确的结束状态为止；可以暂停、恢复、重试 |
| **Session / 会话** | 多次 Run 共享的长期容器：工作区、冻结的系统提示与工具集、只追加的条目树 |
| **Turn / 回合** | 一次模型调用及其后的工具执行。Codex 的定义略有不同：一个 turn 是“一条用户输入到一条 assistant 消息”的全过程 |
| **Step** | 一次工具调用的 journal 记录（intent → result），用于恢复时判断“做没做过” |
| **Event / 事件** | Run 内带单调递增 `seq` 的细粒度事实流，用于流式展示、断线续传、审计与回放 |
| **Entry / 条目** | 会话树上的节点：消息或压缩摘要；只追加，分支只移动 `head` |
| **安全点** | 主循环中可以安全响应取消/暂停的位置：阶段边界、工具结果落盘之后 |

## 消息与模型

| 术语 | 含义 |
|---|---|
| **tool_call / tool_result 配对** | 每个工具调用都必须有一条 `tool_call_id` 相同的结果，否则下一次请求会被 API 拒绝 |
| **content / details** | 工具结果中给模型看的部分与只给 UI/审计的部分（借鉴 pi） |
| **stop_reason** | assistant 消息的结束原因：`end_turn`、`tool_use`、`max_tokens`（参数可能被截断）、`aborted`、`error`、`refusal` |
| **thinking 签名** | Claude 的思考块附带签名，同一模型续写时必须原样回传；编辑早先轮次会让之后的签名失效 |
| **前缀缓存（prompt caching）** | 请求前缀与之前的请求逐字节相同的部分按缓存价计费；依赖“只追加”与确定性序列化 |
| **append-only / 只追加** | 历史从不修改；变化以追加新消息的方式表达 |
| **server-side fallback** | Anthropic 的 `fallbacks` 参数：请求被安全策略拒答时，由服务端在同一次调用里改用备用模型 |
| **ModelInfo / 能力矩阵** | 模型的上下文窗口、最大输出、价格与行为特征（`llm/models.py`） |

## 工具与上下文

| 术语 | 含义 |
|---|---|
| **ACI** | Agent-Computer Interface：把工具当作“给模型用的界面”来设计 |
| **Effect / 副作用等级** | `read`（只读）、`write`（可逆写）、`external`（不可逆/外部影响）；决定并发、重试、审批与取消策略 |
| **外置句柄（blob ref）** | 超大工具结果写入内容寻址存储，上下文只放预览与句柄，按需 `read_ref` / `search_ref` |
| **水位** | 当前上下文占窗口的比例；超过清理阈值清理旧结果，超过压缩阈值做摘要压缩 |
| **compaction / 压缩** | 把较早的历史改写为结构化摘要；有损，是上下文管理的最后一道手段 |
| **切点（cut point）** | 压缩时“从哪条消息开始保留原文”；绝不能落在工具结果上 |
| **system-reminder** | harness 注入给模型的提示（预算、循环、计划复述），以带标记的用户消息形式落盘 |
| **计划复述（recitation）** | 把未完成的计划周期性追加到上下文末尾，缓解长任务的目标漂移 |
| **渐进披露** | 先只给清单（技能、工具摘要），需要时再加载全文 |

## 可靠性

| 术语 | 含义 |
|---|---|
| **CAS 迁移** | `UPDATE … WHERE status=? AND version=?`；影响行数为 0 即并发冲突 |
| **协作式取消** | 取消是请求，各层在安全点自行停下；与之相对的是抢占式取消（`task.cancel()`） |
| **结果未知（unknown）** | 外部操作无法确定是否生效：取消宽限期到期时仍在进行、非幂等的外部调用超时、进程在执行中崩溃；需要对账 |
| **对账（reconcile）** | 凭幂等键向外部系统查询某次操作的真实结果 |
| **幂等键** | 标识“同一次操作”的稳定键；本项目为 `run_id:call_id` |
| **心跳 / 租约** | Worker 定期刷新 `heartbeat_at`（条件更新：租约仍属于自己才成功）；过期视为崩溃，由其它 Worker 接管 |
| **fencing** | 防止旧持有者在失去租约后继续写入；本项目用 `version` 的 CAS 实现：接管时钉住扫描时看到的版本，旧 Worker 发现租约易主后自我取消 |
| **离线迁移** | 没有活动事件流时发生的状态迁移（创建、恢复、离线取消、崩溃接管）；同样写入 `status` 事件，保证每次迁移都有记录 |
| **全抖动（full jitter）** | `uniform(0, min(cap, base·2^n))` 的退避方式，打散大量客户端的重试 |
| **熔断器** | closed → open（快速失败）→ half_open（放一个探测）→ closed；探测被取消或结果不说明健康状况时必须归还名额 |
| **Saga / 补偿** | 多步业务中每一步配一个补偿动作，失败时逆序补偿 |
| **Outbox** | 状态变更与待发布事件在同一事务写入，再异步投递 |

## 策略与执行环境

| 术语 | 含义 |
|---|---|
| **Hook** | 生命周期关键点上的确定性代码：拦截、修改、审计、阻止 |
| **fail-open / fail-closed** | hook 自身出错时放行还是按阻断处理；安全类应 fail-closed |
| **权限模式** | `default`、`accept_edits`、`plan`、`bypass` |
| **规则** | `allow|ask|deny:工具(glob)`，按 deny → ask → allow 顺序先命中者生效 |
| **污点（taint）** | 会话读取过不可信内容（网页下载、开放世界的 MCP 工具、子代理的不可信输出）后，副作用操作升级为人工确认，以对抗提示注入；记录在会话元数据里，暂停恢复后依然有效 |
| **灾难性命令** | 删根目录/家目录、格式化磁盘、写块设备、fork 炸弹等；任何权限模式（包括 bypass）都直接拒绝 |
| **TOCTOU** | 检查时与使用时不一致；审批人修改参数后必须重新校验与判定 |
| **Workspace** | Agent 的工作现场：文件、依赖、执行环境与元数据 |
| **影子 git** | GIT_DIR 放在数据目录、工作树指向工作区的独立仓库，用于快照与回滚 |
| **大脑 / 双手 / 会话** | 模型+harness（无状态）/ 工具与沙箱（可替换）/ 只追加的事件日志（事实源） |

## 多 Agent 与度量

| 术语 | 含义 |
|---|---|
| **子代理** | 在隔离上下文中执行子任务、只回传结构化结论的 Agent |
| **回传契约** | 子代理必须返回的 JSON 结构：status / summary / findings / artifacts / open_questions |
| **Swarm** | 多个 Agent 并行协作完成一个大任务；本项目用 DAG 调度器实现其最小模型 |
| **关键路径** | DAG 中耗时最长的依赖链，决定总耗时 |
| **轨迹（trajectory）** | 一次 Run 的完整记录：输入、每步非确定性结果、控制面事件、上下文指纹 |
| **上下文指纹** | 每次模型调用时“模型看到了什么”（系统提示、工具名/描述/schema、消息）的哈希，用于定位回放分叉点 |
| **确定性回放 / 反事实回放** | 完全按录制结果重放 / 从第 k 步起换用新模型或新提示词 |
| **过早停止率** | 宣称完成但产物检查失败的比例 |
| **Wilson 区间** | 小样本友好的二项比例置信区间 |
| **McNemar 检验** | 同一批用例上比较两个版本的配对检验，只看结论不一致的用例 |
| **OTel GenAI 语义约定** | OpenTelemetry 为生成式 AI 定义的 span 与属性规范（`gen_ai.*`） |
