# flywhl Agent 控制台 · 设计规范

这份文档是 `src/flywhl_harness/web/` 的设计依据。新增页面或组件时先读这里；页面需要偏离时，在 `design-system/pages/<页面>.md` 里写明差异与理由。
令牌的唯一来源是 `web/style.css` 顶部的 `:root`，本文只解释它们的用途与约束。

## 定位与原则

产品类型：开发者工具 / 运维控制台（观察并控制正在执行的 Agent）。风格：极简、Swiss，信息密度优先。

1. **状态先于装饰。** 页面上最显眼的永远是“现在发生了什么、需要我做什么”：运行状态、待审批、错误。不放口号、插画或装饰性动画。
2. **一屏一个主操作。** 会话页的主操作是“发送”，等待审批时是“批准”；其余按钮用次级或幽灵样式。
3. **颜色只承载语义。** 中性色构成界面，蓝色表示可操作与焦点，绿 / 琥珀 / 红只用于成功 / 需注意 / 危险。任何状态都同时有文字与图标，不单靠颜色。
   标识也用这套蓝：文档站的朱红放进控制台会与琥珀、红色的告警语义撞色，也和蓝色主按钮不成一套。
4. **离线可用。** 不加载外部字体、CDN 或图片；图标是内联 SVG。
5. **以服务端为准。** 页面只是事件流的消费者：初次渲染来自持久化状态，增量来自 SSE（按 seq 去重），运行结束后再以持久化状态重绘。

## 令牌

| 类别 | 令牌 | 约束 |
|---|---|---|
| 背景层级 | `--bg` < `--surface` < `--surface-2` < `--surface-3` | 卡片与面板用 `--surface`；悬停、代码块、表头用 `--surface-2/3` |
| 文字 | `--text` / `--text-2` / `--text-3` | 三级都 ≥ 4.5:1（浅色白底与深色面板分别校验）；`--text-3` 只用于辅助信息 |
| 边框 | `--border` / `--border-strong` | 控件用 strong，分隔线用 border |
| 标识 | `--logo`：浅色 `#2563eb`、深色 `#4c8dff` | 与交互蓝同色相；单独成一个令牌，调整标识不影响按钮与焦点 |
| 交互色 | `--brand`（强调、焦点、进度）、`--brand-solid`（实心按钮底色） | 深色主题下 `--brand-solid` 更深，保证白字 ≥ 4.5:1 |
| 语义 | `--success` `--warning` `--danger` `--info` 及 `-soft` 背景 | 只用于状态；危险操作按钮用 `--danger-solid` |
| 间距 | `--sp-1`…`--sp-10`（4px 栅格） | 组件内 8 / 12，区块之间 16 / 24 |
| 圆角 | `--r-sm` 4 · `--r-md` 6（控件）· `--r-lg` 8（卡片）· `--r-xl` 12（输入区、对话框） | 同一层级不混用 |
| 阴影 | `--shadow-sm`（卡片）· `--shadow-md`（输入区、悬停）· `--shadow-lg`（浮层） | 浮层之外不叠加阴影 |
| 动效 | 进入 180ms 减速曲线，离开 120ms 加速曲线，状态变化 120ms | 只做透明度与位移；`prefers-reduced-motion` 时全部关闭 |
| 层级 | sticky 10 · sidebar 30 · dropdown 40 · overlay 90 · modal 100 · toast 110 · palette 120 | 新浮层必须落在这个刻度上 |

字体：系统字体栈（中文优先 PingFang SC / 微软雅黑），等宽字体用于命令、路径、ID、参数与事件。
字号：12（辅助）· 13（密集界面）· 14（基准）· 15（对话正文）· 18（页面标题）· 22（开始页标题）；数字一律等宽数字（`.tnum`）。

## 品牌标识

标识是一个飞轮：外圈、八根辐条与轮毂，图形与文档站 logo（`docs/public/favicon.svg`）完全相同，配色按所在界面适配——
文档站用朱红，控制台用品牌蓝。

| 部位 | 规格 |
|---|---|
| 图形 | 外圈与轮毂实色，辐条 45% 不透明度：小尺寸下层次清楚，不会糊成一个色块 |
| 侧边栏标识 | `index.html` 内联 SVG，`currentColor` 着色，颜色取 `--logo`，随明暗主题切换；30px，不加底板、圆角或阴影 |
| 字标 | 两行：上行 `flywhl harness`（16px；`flywhl` 700、`--text`，`harness` 500、`--text-2`），下行 `Agent 控制台`（12px、`--text-3`） |
| favicon | `web/logo.svg`，经 `/static/logo.svg` 提供；SVG 内用 `prefers-color-scheme` 切换浅色 `#2563eb` / 深色 `#4c8dff` |
| 页面标题 | `<页面> · flywhl harness`，与文档站标题一致 |

`tests/test_runtime.py::test_web_logo_matches_docs_site` 断言三处的几何形状一致；改图形时文档站与控制台一起改。

## 组件与状态

| 组件 | 规则 |
|---|---|
| 按钮 | `primary`（每屏至多一个）、默认（次级）、`ghost`（工具栏）、`danger` / `danger-outline`（破坏性）；图标按钮必须有 `aria-label`；异步操作期间禁用并显示转圈 |
| 状态徽标 | `statusBadge()` 统一生成：图标 + 中文标签 + 色调；只有“此刻正在运行”才显示转圈，历史记录用静态图标 |
| 工具调用卡片 | 一行摘要（图标、工具名、参数摘要、副作用等级、状态、耗时），点开看参数 / 实时输出 / 结果 / diff；出错或结果未知时自动展开 |
| 审批卡片 | 必须回答三个问题：为什么要问（风险等级、原因、命令分析）、会改成什么样（diff 预览）、实际执行什么（可编辑的参数）。拒绝需填写理由（可留空）；参数 JSON 错误就近提示 |
| 对话框 | 焦点进入对话框，Tab 循环在内部，Esc 关闭，关闭后焦点回到触发元素；危险操作默认聚焦“取消” |
| 提示（toast） | 右上角，3–5 秒自动消失，悬停暂停；`aria-live="polite"`，不抢焦点 |
| 菜单 | 方向键移动、Enter 选择、Esc 关闭；单选项用 `menuitemradio` 并标出当前项 |
| 空状态 | 图标 + 一句话说明 + 下一步该做什么 |

## 交互与无障碍

- 深链接：`#/s/<会话>`、`#/runs`、`#/approvals`、`#/tools`；浏览器后退可用。
- 快捷键：`⌘K` 命令面板、`/` 聚焦输入框、`⌘\` 检查器、`⌘Enter` 确认对话框、`Esc` 关闭浮层；输入时不响应单键快捷键。
- 焦点环 2px 品牌色加 2px 间隔，任何控件都不能去掉焦点样式。
- 运行状态变化、审批数量增加用一句完整的话播报（`announce()`），不播报流式 token。
- 触屏设备（`pointer: coarse`）控件高度 ≥ 40px；手机宽度输入框字号 16px，避免 iOS 聚焦放大。
- 断点：≥ 1280 三栏；1024–1279 检查器改为抽屉；< 1024 侧边栏改为抽屉；< 720 隐藏次要信息、表格改为卡片式排列；任何宽度都不出现横向滚动。

## 避免

- 装饰性渐变、网格纸纹理、口号式大标题、为“科技感”加的波形或光效。
- 用 emoji 或字符（⚙ ⚠ ✓）充当界面图标。
- 另画一个“像 logo”的标识，或在控制台里使用文档站的朱红。
- 只靠颜色区分状态；在组件里写裸色值。
- 用浏览器原生 `alert / confirm / prompt`。
- 在用户编辑审批参数时自动重绘卡片（收件箱只在审批集合变化时重绘）。
